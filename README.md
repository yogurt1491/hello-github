# hello-github

我的第一个 GitHub 仓库，用来跑通「本地写代码 -> 提交 -> 推送到 GitHub」的流程。

## 这是什么

一个最简单的 C++ 程序，加上 README 和 .gitignore，
刚好覆盖一个正规仓库该有的基本结构。

## 怎么编译运行

用 Visual Studio 2022 打开 `main.cpp`，按 F5 运行。

或者用命令行：

```
g++ main.cpp -o hello
./hello
```

## 目录结构

```
hello-github/
├── README.md      这份说明
├── .gitignore     告诉 git 哪些文件不用管
└── main.cpp       源代码
```
